Cybersecurity Essentials

Build a strong foundation in digital security, network defense, and ethical security practice through guided labs and realistic scenarios.

Duration8 weeks
FormatLive + practical
OutcomeCertificate

What you will learn

This pathway is designed for beginners who want practical cybersecurity confidence. You will learn the language of security, practice safe investigation habits, and finish with a guided defensive project.

  1. Security foundationsThreats, risk, security principles, and the role of a security professional.
  2. Networks and infrastructureHow devices communicate, where weaknesses appear, and how to read basic network activity.
  3. Defensive monitoringLog review, vulnerability awareness, access control, and incident response fundamentals.
  4. Ethical testing labSafe reconnaissance and common attack patterns inside an instructor-guided lab environment.
  5. Capstone security reviewApply your learning to assess a small system and present practical recommendations.
